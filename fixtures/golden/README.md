# Golden fixtures

These JSON files are the shared game-rules oracle for Paper Glide.

They were generated by executing `Sources/PaperGlideCore` with Swift 6.0.3 on Linux (`scripts/generate-golden.swift` compiled together with the core sources). The iOS release-prep branch (PR A) was not on `origin` when this folder was written, so this is the generator and the format. If PR A lands a different fixture layout, point the Kotlin tests at those files; the simulator in `android/core` is a line-by-line port of `GameSession` and should match within 1e-6.

## Tolerance

- Fixture replay (positions, velocities, flight time, scroll, gap, obstacle layout): absolute error ≤ **1e-6**. Integers (score, ids, phase, scored) are exact.
- Frame rate: the same 1.5s tap script at 60 Hz and 120 Hz matches exactly, because both land on the 1/120 s quantum. 90 Hz leaves a shorter final slice inside each frame, so plane Y may differ. The allowed spread after 1.5 s is **2.0 points**, with the same score, scroll, and gap. The shipped Swift run differs by about 1.55 points.
- Share-card backdrop sample pixels (sky, cloud, facade) match the iOS PNG exactly. The full card, including Fraunces/Nunito, is compared on the emulator: mean channel error ≤ 18 and at least 80% of sampled pixels within 32. Android's text rasterizer is not Core Text.

## Cases

| File | What it locks |
| --- | --- |
| `physics-one-flap-half-second.json` | One flap, spawning off, half a second at 120 Hz |
| `seed1-pilot-until-death.json` | Seed 1, GlidePilot for 40 s (score, ramp, openings) |
| `seed7-scripted-taps.json` | Seed 7, scripted taps, ends in a real collision |
| `rate-60.json`, `rate-90.json`, `rate-120.json` | Same taps, three frame rates |
| `ramp.json` | Opening and scroll at the step boundaries, including the caps at score 60 |
| `sky.json` | SkyCycle samples. The app file imports SwiftUI, so the generator runs the same formulas transcribed into `SkyMath` in the script |

Regenerate from the repo root:

```sh
swiftc -O -o /tmp/generate-golden Sources/PaperGlideCore/*.swift scripts/generate-golden.swift
/tmp/generate-golden fixtures/golden
```
